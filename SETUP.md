# Prince Raval GitHub Profile

## Install it on GitHub

1. Open https://github.com/new
2. Create a **public** repository named exactly `PrinceRaval1706` (same spelling and capitalization as your GitHub username).
3. Do not initialize it with a README, license, or `.gitignore` if you plan to upload these files as-is.
4. Extract this ZIP.
5. Upload `README.md` and the complete `assets` folder to the repository's root.
6. Commit the files. Your profile README should appear at `https://github.com/PrinceRaval1706`.

`preview.html` is an optional local preview. Open it in a browser after extracting the ZIP.

## Before publishing

- Confirm the education/role wording is accurate.
- Add any extra social links you want.
- GitHub stats cards depend on third-party services and may occasionally be unavailable.
- The profile photo is cropped from the photo you supplied.
